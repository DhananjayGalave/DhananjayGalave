Coding Knowledge

HTML (HyperText Markup Language)

  • Understanding of HTML tags (e.g., <div>, <p>, <h1>, <a>, <img>) and document structure.
  • Semantic HTML (using tags like <header>, <nav>, <article>, <footer>).
  • Forms and input elements.
  • Basic understanding of the DOM (Document Object Model).

CSS (Cascading Style Sheets)

  • Selectors (element, class, ID, attribute).
  • Box model (margin, padding, border, content).
  • Layout techniques (flexbox, grid)
  • Typography, text styling, transition and animation.
  • Responsive design (media queries).
  • CSS variables.

JS (JavaScript)

  • Variables, data types, operators.
  • Functions and scope.
  • Control flow (loops, conditionals).
  • DOM manipulation, Event handling.
  • Asynchronous programming (Promises, async/await)
  • Fetch API or XMLHttpRequests.
  • ES6+ features (arrow functions, destructuring, etc.).

Bootstrap

It simplifies CSS development but requires familiarity with its class structure.

  • Grid system (for responsive layouts).
  • Pre-built CSS components (navigation, buttons, forms)
  • JavaScript plugins (modals, carousels).
  • Understanding Bootstrap's class system.

ReactJS

  • JSX (JavaScript XML)
  • Components (functional and class)
  • State and props.
  • Component lifecycle.
  • Hooks (useState, useEffect, etc.).
  • Routing (React Router).
  • State management (Context API, Redux, or similar).
  • API interaction.

Python

  • Basic Python syntax and data structures.
  • Object-oriented programming (OOP) (if using Django or Flask).
  • Understanding of web framework Django.
  • API development.

SQL (Structured Query Language)

  • Database queries (SELECT, INSERT, UPDATE, DELETE)
  • Database schema design.
  • Joins and relationships between tables.
  • Data manipulation and aggregation.

Django

  • Model-View-Template (MVT) architecture.
  • Object-Relational Mapper (ORM).
  • Routing and URL patterns.
  • Template system.
  • Forms and validation.
  • Authentication and authorization.
  • Django Rest Framework for API Development.
